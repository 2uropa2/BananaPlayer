# Banana Player 수익화 플랜 (v1 draft)

> 상태: **보류**. 백본 안정화 우선. 이 문서는 미래 참조용.
> 작성: 2026-08-02.

## 목표

용돈벌이 수준의 부수입 (월 30-150만원 상한). 떼돈 목표 아님. Bandizip / WinRAR 스타일의 광고 지원 무료 + 광고 없는 유료 모델.

## 소스 정책

**클로즈드 소스.** GitHub public 안 함. FFmpeg LGPL은 동적 링크 방식이라 클로즈드 소스 exe 배포 합법 (`LICENSE-3RDPARTY` 이미 커버).

## 인프라 (Phase 0, 1-2일)

### 1. 다운로드 호스팅

- **Cloudflare R2** — S3 호환, 첫 10GB 저장 무료, egress 무료. 강력 추천.
- 27MB 인스톨러 x MAU 5k = 월 100-200GB egress. R2로 사실상 무료.
- 개인 웹호스팅에서 직접 서빙 금지 (트래픽 스파이크 시 요금 폭탄).

### 2. 랜딩 페이지

- 도메인: `banana-player.com` 또는 `bananaplayer.kr` (후이즈/가비아, ~15,000원/yr)
- 호스팅: **Cloudflare Pages** 무료 (private git 저장소 + 자동 배포)
- 정적 HTML 한 장:
    - Banana Player 워드마크 + 태그라인
    - 스크린샷 4-5장
    - "PotPlayer vs GOM vs Banana Player" 비교표 (시작 속도, 설치 크기, 광고 유무)
    - 다운로드 버튼 (R2 URL 링크)

### 3. 코드 서명 인증서 (권장, 선택)

- 없으면 Windows SmartScreen 경고 → 첫인상 나쁨 → 이탈률 증가
- **Sectigo Individual Code Signing** ~$100/yr
- 초반엔 없이 시작, 유저 도달 후 도입 결정

## 자체 업데이트 (Phase 1, 2-3일)

### 4. 원격 버전 체크

- Banana Player 시작 시 하루 1회 페치: `https://banana-player.com/version.json`
- 스키마: `{"latest": "1.4.1", "url": "...", "notes_url": "...", "min_supported": "1.0.0"}`
- 새 버전 있으면 About 패널에 뱃지. 클릭 시 브라우저 열림.
- **자동 다운로드/설치는 하지 마세요.** 유저 신뢰 유지가 자동화보다 중요.

## 광고 인프라 (Phase 2, 1주)

### 5. 스플래시 배너 슬롯

- 스플래시 하단 900x100 배너 자리
- 원격 JSON: `https://banana-player.com/promo.json`
- Banana Player가 하루 1회 페치, 캐시
- **재생 중 광고 절대 없음** — 정체성

### 6. 광고 소스

- **애드핏 (Ad@d)** — 다음/카카오 데스크톱 배너 CPM ~$1-3
- 초반 유저 적을 땐 **자체 프로모** (Banana Player Pro 안내, 개발 블로그)
- **쿠팡 파트너스** 어필리에이트 — 관련 하드웨어 추천

## 유료 버전 (Phase 3, 2주, Phase 2 이후)

### 7. 오프라인 라이선스 키

- 형식: `V4-XXXX-XXXX-XXXX` (12자리 base32)
- 검증: HMAC-SHA256, exe에 하드코딩된 시크릿 + 유저 이메일
- 로컬 검증 (서버 필요 없음)
- 크랙 방지: 소액 유료라 인센티브 낮음. VMProtect / Themida 초반엔 스킵.

### 8. 결제

- **아임포트** — 국내 카드/카카오페이/네이버페이/토스, 수수료 ~3.3%
- **토스페이먼츠** 도 좋음
- **PayPal** — 해외 결제용 (선택)
- 결제 → 자동 이메일: **Postmark** 또는 **AWS SES** ($1-5/월)

### 9. 가격

- **Banana Player Pro**: 9,900원 일회성 (평생) — 한국 시장 편안한 지점
- 또는 3,900원/년 구독 (재구매 유도)
- 첫해는 일회성 권장.

## 재무 예상 (클로즈드 소스 기준)

| 시점 | MAU | 유료 전환율 | 월 수익 (광고+유료) |
|---|---|---|---|
| 3개월차 | 500-1.5k | 0-1% | 1-3만원 |
| 6개월차 | 2-4k | 1-2% | 5-15만원 |
| 12개월차 | 8-15k | 1-2% | 20-60만원 |
| 24개월차 | 25-40k | 2-3% | 70-150만원 |

용돈벌이 상한 월 100-200만원. Bandizip 스케일. 그 이상은 마케팅 조직화 필요.

## 법적 / 세금 체크

- **개인정보처리방침** 필요 (광고 배너 tracking 시)
- **부가통신사업자 신고** 필요 없음 (개인 개발자)
- **소득세** 월 100만원 상회 시 종합소득세 신고
- **사업자 등록** 상시 수익 발생하면 간이과세자 등록 유리 (연 8천만원 이하)
- **저작권**: LICENSE-3RDPARTY 이미 커버 (FFmpeg LGPL / SDL zlib / ImGui MIT)

## 실행 순서 (백본 안정화 완료 후)

1. 도메인 구매 (유저)
2. Cloudflare 계정 + R2 버킷 + Pages (유저)
3. 랜딩 페이지 HTML (내가 초안)
4. Banana Player에 자동 업데이트 체크 코드 추가 (내가 구현)
5. 스플래시 배너 슬롯 뼈대 (내가 구현)
6. 스크린샷 4-5장 (유저)
7. 첫 릴리즈 → 클리앙에 소개 글
8. (선택) 라이선스 키 시스템 + 아임포트 (내가 구현)

## 최우선 리스크

PotPlayer 강력한 유저 락인. 광고 지겨워하는 소수(10-20%)만 이탈시켜도 만 단위 MAU 가능. 그 소수를 잡는 게 전부. 첫 500명 확보가 12개월 후 5,000명으로 자연 증가하는 기폭제.
